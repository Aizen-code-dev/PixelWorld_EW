🎮 Pixelworld: Digital Game Store
Pixelworld is a modern, full-featured e-commerce platform dedicated to digital video games. Built on a robust Java Spring Boot back-end and powered by SQL for persistent data management, this project provides a secure and scalable solution for selling and buying games online.

✨ Key Features
🛍️ E-commerce & Store Functionality
Comprehensive Product Catalog: Browse a vast library of games with rich details, images, and categories.

Secure Cart & Checkout: Seamless and secure multi-step checkout process with robust payment gateway integration.

Digital Product Delivery: Instant and secure delivery of game keys/downloads upon purchase completion.

User Authentication (Spring Security): Secure user registration, login, and role-based access for customers and admins.

Search & Filter: Advanced search, sorting, and filtering options to easily find games by genre, price, or platform.

Wishlist: Users can save games for later purchase.

⚙️ Admin Module
Product Management (CRUD): Dedicated interface for administrators to Create, Read, Update, and Delete game listings.

Order Management: Track and process customer orders, view order history, and update status.

User Management: Administrator tools for managing user accounts and roles.
